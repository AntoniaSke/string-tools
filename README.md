# 🧰 String Tools
Μικρή web εφαρμογή που παρέχει εργαλεία μετατροπής κειμένου, όπως **Convert to UPPERCASE** και **Convert to lowercase**, μέσα από ένα απλό sidebar menu.

## ✨ Features
- 🔤 Μετατροπή κειμένου σε **UPPERCASE**
- 🔡 Μετατροπή κειμένου σε **lowercase**
- 🧭 Sidebar navigation για γρήγορη εναλλαγή εργαλείων
- ⚡ Live εμφανίση αποτελέσματος
- 🧼 Αυτόματο καθάρισμα input και επιστροφή focus μετά το submit
- 🎨 Καθαρό και responsive UI
